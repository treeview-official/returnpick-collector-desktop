# ReturnPick Collector · Electron

반품마켓·골드박스·판매자특가 목록을 천천히 순회하고 JSON / CSV로 저장하는 Windows 수집 전용 앱입니다.

## 사용자 실행

`ReturnPick-Collector-1.1.0-x64-setup.exe`로 설치하거나 `ReturnPick-Collector-1.1.0-x64-portable.exe`를 실행합니다. Python, Node.js, Chrome, Playwriter 별도 설치는 필요하지 않습니다. 인터넷 연결은 필요합니다.

1. 반품마켓, 골드박스 또는 판매자특가를 선택합니다.
2. 필요하면 자동 반복과 30분 / 1시간 주기를 선택합니다.
3. 수집 시작을 누릅니다. 별도 목록 창이 열립니다.
4. 중지하고 저장을 누르면 현재 동작 이후 부분 결과를 저장합니다. 이어서 수집으로 계속할 수 있습니다.
5. 폴더 열기에서 결과를 확인합니다.

기본 저장 위치는 Windows 문서 폴더 아래 `ReturnPick/exports`입니다. 앱 설치 폴더 밖에 저장하므로 앱 업데이트와 분리됩니다. 설정과 중간 체크포인트, 전용 브라우저 세션은 사용자 AppData 아래 보관합니다. 다른 PC에서는 새로 시작하며 로그인 세션을 복사하지 않습니다.

앱과 PC가 켜져 있을 때만 반복합니다. 수집 중 예정 시각이 오면 중복 실행하지 않고 해당 회차를 건너뜁니다. 앱을 닫으면 예약이 끝납니다. 반복 사용 시 첫 시작 버튼을 눌러 예약을 활성화합니다.

## 수집 정보

- 반품마켓: 이미지, 제목, 표시가격, 취소선 가격, 할인율, 반품 등급, 목록 표시 개수, 원본 상품 링크.
- 골드박스: 공통 상품 정보, 판매율, 관측 당시 남은 시간, 예상 종료 시각, 후기 표시/정확성, 별점, 배송 배지와 도착 안내.
- 판매자특가: 전체·건강관리·홈가구전·품절임박·시간임박·인기특가·신규특가 등 페이지에 표시되는 모든 탭을 순서대로 스크롤합니다. 가격/쿠폰·와우 할인 문구, 이미지·제목·원본 링크, 별점·후기 수·배송 안내, 관측 당시 남은 할인 시간과 예상 종료 시각을 저장합니다.
- 판매자특가는 탭마다 바닥에서 높이·위치·상품 수·목록 응답 횟수가 5회 연속 안정되는 것을 확인합니다. 탭별 수집 개수와 완료 여부는 `coverage.categories`, 상품이 발견된 탭은 `sections`에 기록합니다. 탭 간 동일 상품/옵션은 한 건으로 합칩니다.
- 판매자특가의 `90% 남음` 등은 표시 구간값으로 보관합니다. 정확한 재고 수나 판매율로 환산하지 않습니다. 이어 수집은 완료 탭을 건너뛰고 미완료 탭을 처음부터 확인합니다. 탭 변경·목록 응답 오류·시간 제한 시 부분 결과로 저장합니다.
- 상세페이지 탐색과 새 창 이동은 차단합니다. 목록 스크롤과 목록 내 캐러셀만 조작합니다.
- 3초 이상 간격으로 최대 650px씩 내립니다. 마지막 높이·위치·상품 수가 5회 연속 안정적인지 확인합니다.
- 반품마켓은 확인된 카테고리와 캐러셀 전체 이동까지 확인합니다. 사이트 구조가 바뀌어 범위를 검증하지 못하면 부분 결과로 표시합니다.
- 상품/옵션별로 중복을 제거합니다. 반품 표시 개수는 실제 재고와 다릅니다. `9,999+` 후기는 하한값과 원문으로 저장합니다. 없는 값은 추정하지 않습니다.
- 접근 제한, 네트워크 오류, 목록 구조 변경 시 결과가 부분 저장될 수 있습니다. 접근 제한을 우회하는 기능은 없습니다.
- 쿠팡 파트너스 API 호출, 제휴 링크 변환, PHP 서버 업로드는 이 앱의 범위에 포함하지 않습니다. 원본 링크를 저장합니다. 기존 웹사이트에서 제휴 링크 처리를 계속할 수 있습니다.

출력 구조:

```text
exports/
  returns/ 또는 goldbox/ 또는 specials/
    latest.json
    latest.csv
    latest-complete.json       # 정상 완료일 때만 갱신
    <실행시각-목록>/
      products.json
      products.csv
```

## 개발과 빌드

Node.js 24 LTS, Windows x64에서:

```powershell
npm ci
npm test
npm start
npm run smoke
npm run dist
```

Electron/Chromium을 포함하므로 이전 Python EXE보다 파일 용량은 큽니다. 현재 빌드는 코드 서명 인증서가 연결되어 있지 않습니다.

## GitHub 비공개 배포

저장소는 **Private**로 생성합니다. `package.json`의 private 값은 npm 게시 방지용이며 GitHub 접근 권한은 저장소 설정에서 결정됩니다. 비공개 저장소 접근 권한이 있는 계정만 소스·Actions 산출물·Releases를 다운로드할 수 있습니다. 실행 파일 자체에 계정 인증/라이선스 잠금은 없습니다.

`.github/workflows/windows.yml`이 main 변경과 수동 실행에서 검사·Windows 빌드를 수행합니다. `v1.0.0` 같은 태그를 push하면 비공개 초안 Release에 설치형/무설치형 EXE를 첨부합니다. 초안은 저장소에서 확인 후 게시합니다. CI는 GitHub 제공 토큰을 사용하며 앱 안에 GitHub 토큰을 넣지 않습니다. 자동 업데이트는 포함하지 않습니다.

수집 데이터, 브라우저 프로필, 쿠키, API 키, 서버 비밀번호, 설치 파일은 Git 추적 대상에서 제외됩니다. 기존 Python 수집기를 복사해 올리지 않고 이 폴더만 독립 저장소로 사용합니다.

모든 권리 보유. 사용 권한은 저장소 소유자가 부여합니다.
